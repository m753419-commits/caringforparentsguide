监护与授权书：家人需要知道的事

Family Caregiver Practical Guide · 简体中文版更新于 2026年11月4日 · English version

只介绍美国的制度；举例使用得克萨斯州（Texas）和纽约州（New York）的法律，其他州的规定不同。

请注意（Please note）：本文是一般信息，不是法律、财务或医疗建议。

各州规定和费用不同，所以行动之前，请先咨询你所在州的长者法律律师（elder law attorney，专办长者法律问题的律师）、法院协助中心或律师转介服务（纽约州法院（New York Courts）；得州律师公会（State Bar of Texas）；完整免责声明）。

  1. 授权书和监护有什么不同？
  2. 爸妈什么时候该签授权书？
  3. 社会安全局、Medicare 和美国国税局会接受授权书吗？
  4. 什么时候需要监护？
  5. 监护怎么进行？要花多少钱？
  6. 有没有监护以外的替代做法？
  7. 如果代理人或监护人滥用权力怎么办？

授权书和监护有什么不同？

关键差别：授权书（power of attorney，爸妈指定别人代他办事的文件）是爸妈自己签的；监护（guardianship）则是一种法律安排，由法院赋予某人法律权利，替无法自己做决定的人做决定（Texas Estates Code ch. 751；纽约州法院（New York Courts））。

  1. 谁是谁：委托人（principal，签授权书的成年人）指定代理人（agent，被选来代他办事的人）；得克萨斯州（Texas）法律说，代理人也包括“attorney in fact”（代理人的另一种称呼）（TX Estates Code §751.002）。
  2. 持久（durable，爸妈失去决定能力后仍然有效）：在得州，持久授权书必须写明它“is not affected by subsequent disability or incapacity of the principal”（不受委托人日后失能或丧失行为能力影响），或它“becomes effective on the disability or incapacity of the principal”（在委托人失能或丧失行为能力时生效）；丧失行为能力（incapacity）是指再也无法自己做决定（TX Estates Code §751.0021）。
  3. 医疗决定另外处理：在得州，预立医疗指示（advance directive，关于将来医疗照护的文件）可以是一份指示书（directive）、院外 DNR（do-not-resuscitate，不施行心肺复苏）医嘱，或医疗授权书（medical power of attorney）（TX Health & Safety Code §166.002）；在纽约州（New York），有行为能力的成年人可以用医疗代理委托书（health care proxy，指定谁来做医疗决定的表格）指定医疗代理人（NY Public Health Law §2981）。生前预嘱（living will，写明爸妈想要或不想要哪些医疗照护的文件）是另一种常见文件；请看我们的文件清单（英文）。
  4. 两种监护人：纽约州法院说，人身监护人（guardian of the person）可以做生活上的决定，例如医疗、教育和福利方面的决定；另外还有财产监护人（guardian of the property，管理钱和财产的人）；得州则用人身监护人和遗产监护人（guardian of the estate，得州对财产监护人的称呼）（纽约州法院（New York Courts）；TX Estates Code §1002.012）。
  5. 代理人负有义务：纽约州说，代理人和委托人之间是受托关系（fiduciary relationship，依法必须为对方利益行事的义务），包括为委托人的最大利益行事、把委托人的财产分开保管，以及保存记录；得州说，代理人有义务告知委托人，并交代所采取的行动（NY Gen. Oblig. Law §5-1505；TX Estates Code §751.101）。

爸妈什么时候该签授权书？

趁爸妈还能自己做决定的时候：纽约州要求授权书由有行为能力（capacity，能理解自己在签什么）的委托人签署；得州要求成年委托人签署，并办理公证确认（acknowledged，在确认签名的官员面前签名）（NY Gen. Oblig. Law §5-1501B；TX Estates Code §751.0021）。

  1. 得州：必须在获授权为房地产转让契据办理签名确认（确认房产契据上的签名）和主持宣誓（让人宣誓所说属实）的官员面前办理确认（TX Estates Code §751.0021）。
  2. 纽约州：签名必须经过确认，并由两位见证人见证，这两人不能是被指定的代理人或受赠人，而办理确认的人可以当其中一位见证人（NY Gen. Oblig. Law §5-1501B）；医疗代理委托书需要两位成年见证人（NY Public Health Law §2981）。
  3. 得州的授权书什么时候终止：持久授权书在委托人过世或撤销（revoke，取消）时终止，也有其他终止情形，或在永久遗产监护人取得资格时终止（TX Estates Code §751.131）。
  4. 纽约州的授权书什么时候终止：委托人过世、委托人丧失行为能力（如果授权书不是持久的）、委托人撤销，或法院命令撤销时终止（NY Gen. Oblig. Law §5-1511）。
  5. 如果爸妈搬到别的州，请问新州的律师，文件是否要重做；纽约州的法院系统可以帮你找到合适的律师（纽约州法院（New York Courts））。

社会安全局、Medicare 和美国国税局会接受授权书吗？

各有各的表格：社会安全局（Social Security，发放退休和残障福利的联邦机构）说，有授权书和当代领人（收款代理人）不一样，所以你仍然必须申请成为爸妈的代领人（representative payee，由 SSA 指定、代人领取福利的个人或机构）（SSA）。

  1. 社会安全局：对于无法自己管理、也无法指示别人管理社会安全福利或 SSI（Supplemental Security Income，补充保障收入）福利的人，社会安全局会指定一位代领人；而且财政部（Treasury Department，联邦财政部门）不承认用授权书来兑领联邦款项（SSA；我们的文件清单（英文））。
  2. Medicare：联邦医疗保险（Medicare，美国联邦政府为 65 岁及以上人士和部分残疾人士提供的医疗保险）用 CMS-10106 表格，允许 1-800-MEDICARE（Medicare 官方电话，1-800-633-4227）把爸妈的个人健康信息告诉别人，爸妈随时可以更改或取消（CMS-10106 (03/2026)；我们关于 Medicare 授权表格的说明（英文））。
  3. 美国国税局：Form 2848 授权一位有资格在美国国税局（IRS，美国联邦税务机关）执业的人代表爸妈，Form 8821 则让某人可以查看或收到爸妈的保密税务信息（IRS Form 2848；IRS Form 8821）。

什么时候需要监护？

在限制较少的方法都行不通的时候：得州法院必须根据明确且令人信服的证据（clear and convincing evidence，很高的证明标准），认定已经考虑过监护以外的替代做法和现有的支持与服务，而且都不可行；纽约州法院则必须考虑现有资源是否足够、可靠（TX Estates Code §1101.101；NY Mental Hygiene Law §81.02）。

  1. 得州的“无行为能力人”（incapacitated person，法律上指无法自理的人）：因身体或心理状况，在很大程度上无法自己张罗食物、衣服或住所、照顾自己的身体健康，或管理自己财务的成年人（TX Estates Code §1002.017）。
  2. 纽约州：认定丧失行为能力，必须依据明确且令人信服的证据，证明这个人因为无法照顾个人需要或管理财产、而且无法充分了解自己做不到，所以很可能受到伤害；法院会以这个人的实际生活能力为首要考虑（NY Mental Hygiene Law §81.02）。
  3. 得州需要医生的信：没有得州执照医生的书面信函或证明，法院一般不能设立监护（TX Estates Code §1101.103）。
  4. 有限权力：如果爸妈能做一部分事、但不是全部，得州法院可以指定只有有限权力的监护人（TX Estates Code §1101.152）；纽约州采用限制最少的介入方式（least restrictive form of intervention，只给监护人需要的权力，让爸妈尽量保有自主）（NY Mental Hygiene Law §81.03）。

监护怎么进行？要花多少钱？

要经过法院：在纽约州，申请人（petitioner，请求法院开案的人）要填表、递交申请书（petition，请求法院开案的书面请求）、缴交立案费用，并送达文件（正式把副本交给相关的人）；在得州，任何人都可以递交经宣誓的书面申请（纽约州法院（New York Courts）；TX Estates Code §1101.001）。

  1. 纽约州的听证：在法官签署出庭说明令（order to show cause，订下听证日期的法院命令）后 28 天内举行，法院会指定一位法院评估员（court evaluator，替法官调查案情的人）（纽约州法院（New York Courts））。
  2. 临时监护人（temporary guardian，紧急情况下的短期监护人）：当有充分证据显示某人可能丧失行为能力，而且有合理理由（probable cause，有正当理由相信）认为需要立即指定时，得州法院会指定临时监护人；有争议的案件，任期可以持续到满九个月，除非延长（TX Estates Code §§1251.001, 1251.052）；纽约州法院在证明可合理预见的近期内有危险时，可以指定临时监护人（NY Mental Hygiene Law §81.23）。
  3. 费用：各县收费不同，请问法院书记官；纽约州法官可能会要求保证金（bond），它像一份保险，保护丧失行为能力的人不受监护人任何错误的影响（纽约州法院（New York Courts））。
  4. 在纽约州被指定之后：90 天内完成监护人培训课程，在拿到委任状（commission，让监护人可以开始行事的法院文件）后 90 天内递交初次报告，并在每年 5 月 31 日前递交年度报告（纽约州法院（New York Courts））。
  5. 在得州被指定之后：人身监护人每年递交一次报告；遗产监护人在取得资格满一周年后 60 天内递交账目，除非法院延长期限（TX Estates Code §§1163.001, 1163.101）。

有没有监护以外的替代做法？

常常有：纽约州法律列出的现有资源包括上门护士、居家健康助理、成人日间照护（白天有人看顾长者的中心）、授权书、医疗代理委托书、信托，以及代领人和保护性代领人；得州则有《支持性决策协议法》（Supported Decision-Making Agreement Act）（NY Mental Hygiene Law §81.03；Texas Estates Code ch. 1357）。

  1. 得州的支持性决策（supported decision-making，爸妈在信任的人帮助下自己做决定）：法律把它定义为支持和协助残疾成年人、让他能做出生活决定的过程（TX Estates Code §1357.002）。
  2. 在纽约州或其他州，请问律师或法院有没有类似的协议；法院协助中心（Help Centers）为没有律师的人提供免费信息（纽约州法院（New York Courts））。
  3. 找当地服务：Eldercare Locator（长者照护资源查询服务）可以帮你联系为长者和家人提供的服务，电话 1-800-677-1116（Eldercare Locator）。
  4. 和家人一起规划：请看我们的远距离照顾清单（英文）。

如果代理人或监护人滥用权力怎么办？

向法院求助：在得州，受监护人（ward，有监护人的人）或任何关心受监护人福祉的人，都可以请求法院终止或变更监护；在纽约州，法院命令可以撤销授权书（TX Estates Code §1202.051；NY Gen. Oblig. Law §5-1511）。

  1. 纽约州的请律师权利：面临监护的人可以自己选律师；如果他要求律师，或想对申请提出异议，法院必须为他指定律师（NY Mental Hygiene Law §81.10）。
  2. 索取记录：得州的代理人必须及时告诉委托人所采取的每一项行动；纽约州的代理人必须保存所有收入、支出和交易的记录（TX Estates Code §751.102；NY Gen. Oblig. Law §5-1505）。
  3. 找律师：得州律师公会律师转介服务（State Bar of Texas Lawyer Referral Service），(800) 252-9690（State Bar of Texas）；纽约州的法院系统可以帮你找到合适的律师（纽约州法院（New York Courts））。
  4. 如果爸妈有立即的危险，请拨打 911。
  5. 预防家人纠纷：请看怎么避免为爸妈的钱起纠纷（英文）。
