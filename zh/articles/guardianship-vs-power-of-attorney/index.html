監護與授權書：家人需要知道的事

Family Caregiver Practical Guide · 中文版更新於 2026年11月10日 · English version

只介紹美國的制度；舉例使用德州（Texas）和紐約州（New York）的法律，其他州的規定不同。

請注意（Please note）：本文是一般資訊，不是法律、財務或醫療建議。

各州規定和費用不同，所以行動之前，請先諮詢你所在州的長者法律律師（elder law attorney，專辦長者法律問題的律師）、法院協助中心或律師轉介服務（紐約州法院（New York Courts）；德州律師公會（State Bar of Texas）；完整免責聲明）。

  1. 授權書和監護有什麼不同？
  2. 爸媽什麼時候該簽授權書？
  3. 社會安全局、Medicare 和美國國稅局會接受授權書嗎？

  5. 監護怎麼運作？要花多少錢？

授權書和監護有什麼不同？

關鍵差別：授權書（power of attorney，爸媽指定別人代他辦事的文件）是爸媽自己簽的。監護（guardianship）則是一種法律安排，由法院賦予某人法律權力，讓他替無法自己做決定的人做決定（Texas Estates Code ch. 751；紐約州法院（New York Courts））。

  1. 誰是誰：委託人（principal，簽授權書的成年人）指定代理人（agent，被選來代他辦事的人）；德州（Texas）法律說，代理人也包括「attorney in fact」（代理人的另一種稱呼）（TX Estates Code §751.002）。
  2. 持久（durable，爸媽失去決定能力後仍然有效）：在德州，持久授權書必須寫明它「is not affected by subsequent disability or incapacity of the principal」（不受委託人日後失能或喪失行為能力影響），或它「becomes effective on the disability or incapacity of the principal」（在委託人失能或喪失行為能力時生效）；喪失行為能力（incapacity）是指再也無法自己做決定（TX Estates Code §751.0021）。
  3. 醫療決定另外處理：在德州，預立醫療指示（advance directive，關於將來醫療照護的文件）可以是一份指示書（directive）、院外 DNR（do-not-resuscitate，不施行心肺復甦）醫囑，或醫療授權書（medical power of attorney）（TX Health & Safety Code §166.002）；在紐約州（New York），有行為能力的成年人可以用醫療代理委託書（health care proxy，指定誰來做醫療決定的表格）指定醫療代理人（NY Public Health Law §2981）。生前預囑（living will，寫明爸媽想要或不想要哪些醫療照護的文件）是另一種常見文件；請看我們的文件清單（英文）。
  4. 2 種監護人：紐約州法院說，人身監護人（guardian of the person）可以做生活上的決定，例如醫療、教育和福利方面的決定；另外還有財產監護人（guardian of the property，管理錢和財產的人）；德州則用人身監護人和遺產監護人（guardian of the estate，德州對財產監護人的稱呼）（紐約州法院（New York Courts）；TX Estates Code §1002.012）。
  5. 代理人負有義務：紐約州說，代理人和委託人之間是受託關係（fiduciary relationship，依法必須為對方利益行事的義務），包括為委託人的最大利益行事、把委託人的財產分開保管，以及保存記錄；德州說，代理人有義務告知委託人，並交代所採取的行動（NY Gen. Oblig. Law §5-1505；TX Estates Code §751.101）。

爸媽什麼時候該簽授權書？

趁爸媽還能自己做決定的時候：紐約州要求授權書由有行為能力（capacity，能理解自己在簽什麼）的委託人簽署；德州要求成年委託人簽署，並辦理公證確認（acknowledged，在確認簽名的官員面前簽名）（NY Gen. Oblig. Law §5-1501B；TX Estates Code §751.0021）。

  1. 德州：必須在獲授權為房地產轉讓契據辦理簽名確認（確認房產契據上的簽名）和主持宣誓（讓人宣誓所說屬實）的官員面前辦理確認（TX Estates Code §751.0021）。
  2. 紐約州：簽名必須經過確認，並由 2 位見證人見證，這兩人不能是被指定的代理人或受贈人；辦理確認的人可以兼任其中一位見證人（NY Gen. Oblig. Law §5-1501B）；醫療代理委託書需要 2 位成年見證人（NY Public Health Law §2981）。
  3. 德州的授權書什麼時候終止：持久授權書在委託人過世、撤銷（revoke，取消）或出現其他終止情形時終止，永久遺產監護人取得資格時也會終止（TX Estates Code §751.131）。
  4. 紐約州的授權書什麼時候終止：委託人過世、委託人喪失行為能力（如果授權書不是持久的）、委託人撤銷，或法院命令撤銷時終止（NY Gen. Oblig. Law §5-1511）。
  5. 如果爸媽搬到別的州，請問新州的律師文件要不要重做；紐約州的法院系統可以幫你找到合適的律師（紐約州法院（New York Courts））。

社會安全局、Medicare 和美國國稅局會接受授權書嗎？

各有各的表格：社會安全局（Social Security，發放退休和失能福利的聯邦機構）說，有授權書不等於是代領人，所以你還是必須申請成為爸媽的代領人（representative payee，由 SSA 指定、代人領取福利的個人或機構）（SSA）。

  1. 社會安全局：對於無法自己管理、也無法指示別人管理社會安全福利或 SSI（Supplemental Security Income，補充保障收入）福利的人，社會安全局會指定一位代領人；而且財政部（Treasury Department，聯邦財政部門）不承認用授權書來兌領聯邦款項（SSA；我們的文件清單（英文））。
  2. Medicare：聯邦醫療保險（Medicare，美國聯邦政府為 65 歲及以上人士和部分身心障礙者提供的醫療保險）用 CMS-10106 表格，允許 1-800-MEDICARE（Medicare 官方電話，1-800-633-4227）把爸媽的個人健康資訊告訴別人，爸媽隨時可以更改或取消（CMS-10106 (03/2026)；我們關於 Medicare 授權表格的說明（英文））。
  3. 美國國稅局：Form 2848 授權一位有資格在美國國稅局（IRS，美國聯邦稅務機關）執業的人代表爸媽，Form 8821 則讓某人可以查看或收到爸媽的保密稅務資訊（IRS Form 2848；IRS Form 8821）。

什麼時候需要監護？

在限制較少的方法都行不通的時候：德州法院必須根據明確且令人信服的證據（clear and convincing evidence，很高的證明標準），認定已經考慮過監護以外的替代做法和現有的支持與服務，而且都不可行。紐約州法院則必須考慮現有資源是否足夠、可靠（TX Estates Code §1101.101；NY Mental Hygiene Law §81.02）。

  1. 德州的「無行為能力人」（incapacitated person，法律上指無法自理的人）：因身體或心理狀況，在很大程度上無法自己張羅食物、衣服或住所、照顧自己的身體健康，或管理自己財務的成年人（TX Estates Code §1002.017）。
  2. 紐約州：認定喪失行為能力，必須依據明確且令人信服的證據，證明這個人無法照顧個人需要或管理財產，而且無法充分了解自己做不到，因此很可能受到傷害；法院會以這個人的實際生活能力為首要考慮（NY Mental Hygiene Law §81.02）。
  3. 德州需要醫生的信：沒有德州執照醫生的書面信函或證明，法院一般不能設立監護（TX Estates Code §1101.103）。
  4. 有限權力：如果爸媽能做一部分事、但不是全部，德州法院可以指定只有有限權力的監護人（TX Estates Code §1101.152）；紐約州採用限制最少的介入方式（least restrictive form of intervention，只給監護人需要的權力，讓爸媽儘量保有自主）（NY Mental Hygiene Law §81.03）。

監護怎麼運作？要花多少錢？

要經過法院：在紐約州，申請人（petitioner，請求法院開案的人）要填表、遞交申請書（petition，請求法院開案的書面請求）、繳交立案費用，並送達文件（正式把副本交給相關的人）；在德州，任何人都可以遞交經宣誓的書面申請（紐約州法院（New York Courts）；TX Estates Code §1101.001）。

  1. 紐約州的聽證：在法官簽署出庭說明令（order to show cause，訂下聽證日期的法院命令）後 28 天內舉行，法院會指定一位法院評估員（court evaluator，替法官調查案情的人）（紐約州法院（New York Courts））。
  2. 臨時監護人（temporary guardian，緊急情況下的短期監護人）：當有充分證據顯示某人可能喪失行為能力，而且有合理理由（probable cause，有正當理由相信）認為需要立即指定時，德州法院會指定臨時監護人；有爭議的案件，任期可以持續到滿 9 個月，除非延長（TX Estates Code §§1251.001, 1251.052）；如果能證明在可合理預見的近期內有危險，紐約州法院可以指定臨時監護人（NY Mental Hygiene Law §81.23）。
  3. 費用：各縣收費不同，請問法院書記官。另外，紐約州法官可能會要求保證金（bond），它像一份保險，保護喪失行為能力的人不會因監護人的任何錯誤而受損（紐約州法院（New York Courts））。
  4. 在紐約州被指定之後：90 天內完成監護人培訓課程，在拿到委任狀（commission，讓監護人可以開始行事的法院文件）後 90 天內遞交初次報告，並在每年 5 月 31 日前遞交年度報告（紐約州法院（New York Courts））。
  5. 在德州被指定之後：人身監護人每年遞交 1 次報告；遺產監護人在取得資格滿一週年後 60 天內遞交帳目，除非法院延長期限（TX Estates Code §§1163.001, 1163.101）。

有沒有監護以外的替代做法？

常常有：紐約州法律列出的現有資源包括上門護士、居家健康助理、成人日間照護（白天有人看顧長者的中心）、授權書、醫療代理委託書、信託，以及代領人和保護性代領人；德州則有《支持性決策協議法》（Supported Decision-Making Agreement Act）（NY Mental Hygiene Law §81.03；Texas Estates Code ch. 1357）。

  1. 德州的支持性決策（supported decision-making，爸媽在信任的人幫助下自己做決定）：法律把它定義為支持和協助身心障礙成年人、讓他能做出生活決定的過程（TX Estates Code §1357.002）。
  2. 在紐約州或其他州，請問律師或法院有沒有類似的協議；法院協助中心（Help Centers）為沒有律師的人提供免費資訊（紐約州法院（New York Courts））。
  3. 找當地服務：Eldercare Locator（長者照護資源查詢服務）可以幫你聯絡為長者和家人提供的服務，電話 1-800-677-1116（Eldercare Locator）。
  4. 和家人一起規劃：請看我們的遠距離照顧清單（英文）。

如果代理人或監護人濫用權力怎麼辦？

向法院求助：在德州，受監護人（ward，有監護人的人）或任何關心受監護人福祉的人，都可以請求法院終止或變更監護。在紐約州，法院命令可以撤銷授權書（TX Estates Code §1202.051；NY Gen. Oblig. Law §5-1511）。

  1. 紐約州的請律師權利：面臨監護的人可以自己選律師；如果他要求請律師，或想對申請提出異議，法院必須為他指定律師（NY Mental Hygiene Law §81.10）。
  2. 索取記錄：德州的代理人必須及時告訴委託人所採取的每一項行動；紐約州的代理人必須保存所有收入、支出和交易的記錄（TX Estates Code §751.102；NY Gen. Oblig. Law §5-1505）。
  3. 找律師：德州律師公會律師轉介服務（State Bar of Texas Lawyer Referral Service），(800) 252-9690（State Bar of Texas）；紐約州的法院系統可以幫你找到合適的律師（紐約州法院（New York Courts））。
  4. 如果爸媽有立即的危險，請撥打 911。
  5. 預防家人糾紛：請看怎麼避免為爸媽的錢起糾紛（英文）。
